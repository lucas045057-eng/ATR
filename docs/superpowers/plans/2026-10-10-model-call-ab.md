# 模型调用 A/B 实验执行计划

**目标：** 在同一现有 API 容器中实际比较 httpx 直连与 ATR 原有独立 Worker，形成可核验的中文报告。

**架构：** 独立实验脚本复用正式 Worker、外层进程超时、调查 Prompt 和验证器；仅在实验子进程注入安全 HTTP 观测。原始消息、响应和凭据只存在内存与原有 Worker 管道，不写入实验文件。

**技术：** 现有 Python/httpx/httpcore/OpenAI SDK/LiteLLM，不安装依赖。

**依据：** 当前用户的《ATR V2.2｜真实模型调用链路 A/B 对照实验》完整要求；用户已要求直接实施，无需另行审批计划。

## 约束与检查重点

- 初始真实 API 上限 4 次；用户随后明确取消总次数限制。仍只执行有理由的单次/成对探针，发送前占用不可重复使用的实验名额，所有自动重试为 0。本轮最终24次。
- 每条路径内部请求超时 120 秒、进程硬超时 130 秒；不修改正式配置。
- 两条路径必须观测实际 URL、JSON 字段、消息摘要和请求大小；不能只比较函数参数。
- headers/body 时间只标注实际可测事件，不把响应头到达伪称首个响应字节。
- 输出合法性失败与 HTTP/网络/进程失败分别记录；从不执行工具。
- 禁止输出请求/响应内容、密钥及非白名单头；保留业务数据库、文件、授权、Git 状态。
