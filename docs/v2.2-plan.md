# ATR V2.2 Implementation Plan

> **For agentic workers:** 执行用户授权的增量任务；按 test-driven-development 和 verification-before-completion 逐阶段验证。三个互不重叠的 P0 域按 dispatching-parallel-agents 并行处理，其余依赖阶段顺序实施。

**Goal:** 安全、预算有界的多轮自适应故障调查。
**Architecture:** 在原 LangGraph 和 SQLite 上增量增加规划、因果校验、快照时效与任务原子约束。
**Tech Stack:** FastAPI / SQLite / LangGraph / LiteLLM / React。
**Spec:** [v2.2-design.md](v2.2-design.md)，用户 ATR V2.2 任务书。
