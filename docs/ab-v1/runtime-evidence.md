# AB v1 运行证据与来源约束

服务范围确认只证明运行对象属于该业务和目标。完整故障链还需要确认消费者到依赖的有向连接地址。健康检查的 endpoint_id 是授权请求标识，不等于依赖连接的 host:port。

在“服务器与服务”读取明确授权的当前配置文件后，从“确认服务连接地址”选择配置候选和依赖关系，核对实际使用的消费者配置并填写依据。后台要求依赖两端都有同一目标中唯一、当前有效的运行对象；配置读取完整，且不超过一天。确认保存为带观测来源的人工审核事实，不能由模型自动确认。

图中保存每个目标的映射；调查只投影与本次目标、两端运行绑定相符的映射。每次判定重新检查配置和绑定。路径先规范化，较新的同文件配置读取、到期或运行对象失效使旧映射不再可用。缺少映射仍是强制证据缺口。日志的故障类型和连接地址必须来自同一条带时间的事件，不能拼接其他日志行。

图视图同时冻结资料版本和图快照。切换主题、结构与流程不读取新的图快照；点击“更新到最新资料版本”才更新。图中来源保留准确文件、页码、区域或运行观测。已否决或失效的事实不绘制为有效关系；审核文档内容不把它变成运行证据。导出通过核对快照和随机令牌的父页面接收已生成文件，嵌入页没有访问令牌或同源权限。

源码只解析，不能导入或执行。同名函数按声明位置区分；不能证明唯一分发的调用保持未知。请求宿主和处理器要核对词法绑定，参数遮蔽或重新赋值不能借用外层同名对象。条件中的字符串字面量不进入模型请求；凭据相关数据操作保持脱敏。

“从原资料断点恢复”沿用原资料标识、原始字节摘要和已保存页面。恢复前校验上传文件、清单和每个文件的摘要。已完成页面和与当前模型、模式及提示词匹配的视觉结果可复用。显式恢复创建新的有界初始批次，不因自动轮询补充预算。解包尚未完成的目录保留后重新处理，连续三次中断后停止自动恢复并保留原件。已经登记的文件沿用原标识；历史画像不被覆盖。

新调查、预算、执行记录及后台任务关联在同一个数据库事务中提交；准备失败不能留下已排队但没有执行记录的调查。等待范围确认的调查可以取消，取消后的晚到证据不能改变结果。

模型设置使用加密原子替换。并发保存时重新读取当前密钥，空白密钥不会恢复旧请求捕获的密钥。实际调用前核对当前设置修订和外部分析授权；变更后的旧设置不能继续发送资料。
