# ATR V2.3：任务驱动的自主调查收敛与停止机制

## 目的

让调查围绕用户选定的任务目标收敛。Runtime 按证据进展、任务所需检查、授权候选和 Evidence Gate 决定何时停止；不因候选动作仍存在或模型想继续推理而无限延长调查。

## 任务类型与 Run 快照

新建业务 Runtime Run 可选择：

| 任务 | 默认软上限（模型轮数 / 工具调用） | 完成条件 |
|---|---:|---|
| 健康检查 | 3 / 4 | 目标服务状态已记录，日志已检查或明确不可用 |
| 定向诊断（默认） | 5 / 6 | 目标服务直接状态及必要日志已检查；触发原因可以保持未知 |
| 根因调查 | 12 / 20 | Evidence Gate 确认根因，或在授权检查耗尽、无进展、软上限时报告证据缺口 |

软上限来自 `backend/app/settings.py` 的 `TASK_HEALTH_*`、`TASK_FOCUSED_*`、`TASK_RCA_*` 设置，并由 `INVESTIGATION_MODEL_ROUNDS`、`INVESTIGATION_TOOL_CALLS` 的现有硬上限封顶。无进展轮数默认为 2，实用检查分数阈值默认为 3.5，高价值阈值默认为 4.5。硬预算优先；软上限只允许一次已有活跃假设指向的高价值只读检查，之后停止。

根因调查最多绑定 20 个已授权服务节点；超出的唯一节点数量保存在 Run 目标中并在调查结果页明确显示，结果不能标为无缺口完成或“范围内未观察到故障”。

Run 创建时将任务类型、目标服务、必需检查和停止策略写入既有 Run 模型配置快照；计划进度、内容指纹、Claim 状态和停止原因写入 Run 摘要。暂停、审核后恢复会继续使用原任务快照，只有待审核 Run 在人工确认映射后才绑定目标节点。历史 Run 不补造任务目标：缺少此快照的 Run 继续使用原有 `legacy_v22` 协议。

任务目标只从当前业务图和 Run 已确认的服务映射解析。健康检查和定向诊断限于首要授权服务；根因调查可检查任务目标范围内的已授权依赖。任务选择不扩大 SSH Target、工具白名单、容器/路径授权或服务映射。

## 运行流程

1. Runtime 建立有界的目标、状态/日志必需检查及可选检查计划。
2. 现有只读工具策略生成动作候选；定向任务只看到未完成的必需检查，根因调查只使用任务范围内的授权候选。
3. 模型决策之前，Runtime 先检查硬预算、Evidence Gate、任务完成、候选是否有用、连续无进展及任务软上限。任务已完成或没有有效候选时不调用模型。
4. 工具结果以证据记录；进展按目标状态、去除时间戳后的日志内容指纹和 Claim 状态变化计算。单纯新增证据行、时间戳或假设重复不等同于进展。
5. 若模型建议结束，Runtime 只会在存在未完成必需检查或当前活跃假设上的高价值授权检查时保留一个精确候选，并把覆盖原因、候选和证据缺口写入审计。该候选随后按原授权再次解析和执行；Evidence Gate 已支持时绝不绕过其结束决定。
6. 最终摘要分别呈现任务完成状态、根因状态、已完成/不可用/未完成检查和停止原因。健康状态仅描述本次已执行的只读观察，不宣称 HTTP 或端到端业务一定健康。

## 兼容与安全边界

- 新的自适应业务 Run 使用带任务停止策略的 `minimal_v2`；Graph-only、Pattern 对照和其他历史路径沿用原流程。
- 旧 `legacy_v22` 协议仍允许对业务图中的服务提出范围审核请求；实际工具调用依旧只来自已确认映射的安全候选。新 Runtime 的模型节点候选与校验器使用同一任务节点集合。
- Evidence Gate、事实/Claim 约束、工具白名单、SSH Target 绑定、授权映射、预算和只读策略保持原样；未知服务、未授权动作不会因任务类型而被执行。
- 不增加模型重试、不放宽验证、不提高全局预算，不将原始模型响应、Prompt 或日志写入停止策略摘要。
- Run 配对比较忽略随机生成的 `task_id`，但仍比较任务类型、目标范围和停止策略，避免因实例 UUID 不同误判配置不一致。

## 回归覆盖

`tests/test_task_stop_policy.py` 覆盖任务默认值、计划与授权过滤、证据指纹进展、重复动作/假设、两轮无进展、硬/软预算、一次高价值收尾动作、Gate 不能提前通过、损坏快照失败关闭、Run 快照恢复和目标绑定及范围截断披露。`tests/test_v23_decision_runtime.py` 覆盖新旧协议、健康范围与直接故障场景、范围不完整时不报告健康，以及仅对未被当前 Claim 反证的假设保留高价值检查。`tests/test_v22_adaptive.py` 覆盖旧协议范围审核及工具不越权。
