# ATR V2.2 Ponytail 审计与优化报告

日期：2026-10-11。范围：当前本地未提交的 V2.2 功能，以及本次最小优化。未连接生产服务器，未调用真实付费模型。

## 审计结论

现有独立模型 Worker、SSH 密码/私钥、固定只读工具、显式 Run 目标绑定、人工映射审核和证据门保持有效。本次发现并修正了重复模型上下文、预算错误缺少具体限制和数值，以及测试读取操作者本地预算导致结果不稳定的问题。没有重构 Agent、增加依赖、扩大工具权限或提高默认预算。

## 本次最小改动

1. 调查模型上下文始终先删除与当前假设完全相同的历史摘要。历史状态变化仍可保留；原始假设、反证和调查步骤不变。
2. 模型侧候选动作省略重复权限标志，历史动作省略哈希；当前候选 action_id、实际参数和后端授权校验保留。完整动作仍进入审计。
3. BudgetExceeded 携带安全的停止原因、输入估算及单次限制。调查、初始理解和发现阶段沿现有错误通道显示；预检查拒绝不伪造已发送请求或供应商 usage。已发送请求的审计另外保留预检查估算。
4. 页面解释单次输入、累计 Token、上下文容量等限制；输入估算明确标为 UTF-8 字节加固定开销。
5. 测试固定使用默认初始、调查和累计预算，避免读取操作者 `.env` 的预算覆盖。新增后端及真实浏览器回归测试。
6. 排除 pytest 临时目录进入 Git 和 Docker 构建上下文。未被代码引用的个人照片保留在本地并排除同步；`.env`、数据库、上传资料、测试凭据和测试结果均不提交。
7. 更新 README 和预算说明，明确 SSH 两种认证、两种执行边界、Run 目标绑定、审核恢复及配置生效范围。
