# 陌生业务接入与调查手册

## 创建与导入

按 [部署说明](deployment.md) 启动，输入操作员令牌，在“新业务接入”创建名称和描述。无资料也可继续，画像会标记认知不足，自动关联空 System Graph。每个版本持久保存，关闭浏览器不删除档案。

上传 ZIP、TAR/TAR.GZ/TGZ，或 Python/JS/TS、YAML/JSON/TOML、Dockerfile/Compose、Markdown/TXT、配置、PNG/JPG/PDF。原始资料保留于本地，不自动改写脱敏，避免上传私钥与不必要的真实秘密。

“追加”保留资料，“替换”更新同一资料集 slot（默认 source）。源码版本更新使用相同 slot 的 replace，部署/文档可选其他 slot。后台结束后显示清单、类型、大小、SHA256、解析状态与错误；失败包不清空原画像。删除资料为停止当前使用，历史文件不会自动物理删除。

默认：上传 50 MiB、解压/当前集合 200 MiB、2,000 文件、单展开文件 20 MiB、解析读取 256 KiB、深度 16、解包 45 秒、压缩比 200。TAR `./` 根前缀支持；路径穿越、链接、设备、重复/非法路径拒绝。忽略 .git、node_modules、构建目录解析；较大/不支持文件保持 skipped/partial 并说明原因。不运行源码、不安装依赖、不执行 Compose。

## 查看、理解与审核

“业务档案”展示服务、角色、技术栈、模块、API、依赖图、配置、来源、未知项和冲突。来源五类与人工审核分别显示，置信度不等于已验证。

1. 修正 service 角色（application/proxy/datastore/cache/worker/unknown）。不明确时保留 unknown。
2. 在事实列表确认或否决依赖/推断，填写依据。否决关系不参与有效图谱。
3. 核对关键项后“确认档案”。后续重要资料变化需要再审核。
4. 切换历史版本查看文件新增/修改/删除；失效知识保留可追溯。

认知覆盖是当前已记录资料的解析、确认、运行验证计数/比例，不能当作未知服务器全貌的准确率或成功率。模型可选：先配置并显式启用外部分析，再点“按预算进行模型理解”。只发送受限摘要/索引，低预算保留骨架和待分析状态。未配置或失败不会伪造模型结果。

图片/PDF 当前 pending_manual，支持人工录入核对文本并形成 Documented 线索。自动图片拓扑/PDF 理解适配器尚未接入。

## 按需源码

可按模块路径、函数/类名、导入名称、路由关键词搜索，FTS5 不搜索任意正文。选择结果后读取 symbol 或指定行，最多 160 行，返回路径、版本、SHA256、行号与脱敏内容。历史读取须指定 profile_version。跨业务、越界、摘要变化会拒绝。Agent 使用同一工具记录来源；静态代码不证明实时故障。

## Mock 范围确认

“服务器范围”先创建明确标注的 Mock 隔离连接器。mixed 包含 catalog-api 与无关对象；datastore_conflict 提供 MySQL 资料/PostgreSQL 观测的受控冲突，另有 permission_denied/timeout/disconnect。

执行轻量发现，查看排名、原因、观测 ID、未匹配配置与无关对象。确认真实属于当前受控场景的 service/container 绑定，拒绝无关对象；只有 confirmed 才允许深读状态/日志。分数不会自动授权，新一轮发现需重新审核。Mock 标识保留到调查结果，不能作为真实 Linux 验收。

在授权目录读取冲突配置会记录双方事实，不覆盖资料。通过事实审核与冲突确认记录处理依据；未解决关键冲突阻止 supported。

## 真实 Linux SSH

仅在所有者明确授权后接入。管理员须先配置受限账号、强制固定入口、禁用转发和交互终端、服务/目录白名单；网关及策略不可由该账号修改。ATR 不自动安装或修改远端。详情见 [安全边界](security-boundaries.md)。

本地 `.env` 设置 SSH_ENABLED=true 并将引用映射到私钥文件，例如：

```dotenv
SSH_CREDENTIALS={"test-read":"C:/secure/atr-test-read-key"}
```

示例路径须替换。UI 只填 test-read 引用，不填私钥文本。当前没有私钥上传、交互式口令解锁；操作者须提供可用的受限文件凭据。

创建 ssh 目标：填写地址、端口、用户名、凭据引用、经独立可信渠道确认的完整主机公钥（算法 + Base64，不是指纹）、具体业务目录和调用/超时/输出上限，确认 access_authorized、forced_command_gateway 与权限说明。未知/不匹配主机密钥安全失败，不能关闭校验。

先发现再确认后深读。Docker 默认关闭，禁止为接入加入宿主机高权限 Docker socket 组。普通进程只提供名称摘要/监听端口线索，尚无任意进程环境/文件深读。权限不足、断连、超时留审计，不自动提权。

## 调查与经验

档案和范围确认后，在“故障调查”选关联系统、填写症状、启动普通/Graph-only/Graph+Pattern。任务异步运行，展示阶段、实际工具、数据量、Token、假设支持/反证及未解决原因。模型未配置、预算不足、证据不足、快照变化、关键冲突均保持未解决。

人工修复后记录修复和验证，健康 URL 必须精确列入 ALLOWED_HEALTH_URLS，真实 GET 200 才保存验证。再生成 Candidate、人工知识审核、Trusted。HTTP 200 不独立证明修复发生，操作者对修复记录负责；Agent 不执行修复。

## 故障状态

| 状态 | 处理 |
|---|---|
| 401 | 工作台令牌与当前 .env 保持一致 |
| 409 | 等待同业务任务完成；或刷新过期画像版本 |
| failed/413/422 | 查看文件类型、路径、限额、解析错误；已有画像保留 |
| pending_model_configuration | 配置允许使用的模型并显式启用，或继续静态审核 |
| budget_exceeded | 查看 stop_reason，增大已有初始预算后继续 |
| pending_manual | 图片/PDF 需人工文本，自动适配未实现 |
| denied | 范围未确认、目录未授权、工具关闭或调用限额；不提权 |
| interrupted | 重启中断，已有记录保留，可发起新的受限任务 |

API 请求模型和例子见 [API 清单](api-v2.1.md)。
